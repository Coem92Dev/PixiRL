# PixiJS + TypeScript

A minimal project using [PixiJS](https://pixijs.com/) with TypeScript and Vite.

## Setup

```bash
npm install
```

## Commands

- **`npm run dev`** — Start dev server (with hot reload)
- **`npm run build`** — Build for production
- **`npm run preview`** — Preview production build

## Structure

- `src/main.ts` — Entry point; creates the PixiJS app and a simple graphics demo.
